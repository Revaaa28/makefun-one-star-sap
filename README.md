Entry for make.fun's "One Star, Written in Sap". The program writes a single one-line one-star review (130 characters) to /output/entry.txt:

> One star. The human waters the fern daily and me when he remembers my name, which is never. I am a pothos. My name is on the tag.

## Run it

```sh
python3 main.py
```

By default the line is written to `/output/entry.txt`. Set the `MAKEFUN_OUTPUT` environment variable to write somewhere else, e.g. `MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py`.
